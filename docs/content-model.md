# 内容模型草案

网站目前使用 `docs/info.md` 作为给 Zayn 编辑的内容控制文档。修改后由 Codex 读取并同步到网页；这样不需要维护登录、数据库或传统后台，也保留了后续升级为自动控制台的空间。

## 网站公告 `siteNotice`

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `title` | 文本 | 公告标题 | `Moving Sale` |
| `availability` | 文本 | 当前联系或取货状态 | `Weekdays after 6 PM` |
| `pickupDeadline` | 日期 | 最晚取货日期 | `2026-08-31` |
| `pickupArea` | 文本 | 取货区域，可保持模糊 | `Downtown` |
| `notes` | 文本列表 | 通用交易说明 | `Pickup only` |
| `updatedAt` | 日期时间 | 信息最后更新时间 | `2026-08-22T12:00:00-07:00` |

## 商品 `item`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | 文本 | 是 | 稳定且唯一的商品 ID |
| `slug` | 文本 | 是 | 用于商品详情页网址 |
| `name` | 文本 | 是 | 商品名称 |
| `summary` | 文本 | 是 | 列表页的一句话说明 |
| `description` | 富文本 | 否 | 完整介绍、交易说明或使用感受 |
| `price` | 数字 | 否 | 售价；不公开价格时可留空 |
| `currency` | 文本 | 否 | 货币，例如 `USD` |
| `status` | 枚举 | 是 | `available`、`reserved`、`sold` |
| `images` | 图片列表 | 是 | 主图放在第一张，支持后续追加图片 |
| `specs` | 键值列表 | 否 | 品牌、型号、尺寸、颜色等参数 |
| `condition` | 文本 | 否 | 新旧程度和使用情况 |
| `defects` | 文本列表 | 否 | 瑕疵应尽量明确说明 |
| `pickupNotes` | 文本 | 否 | 该商品特有的取货要求 |
| `featured` | 布尔值 | 否 | 是否优先展示 |
| `createdAt` | 日期时间 | 是 | 添加时间 |
| `updatedAt` | 日期时间 | 是 | 最后更新时间 |

## 状态显示建议

| 状态 | 中文含义 | 页面行为 |
| --- | --- | --- |
| `available` | 可购买 | 正常展示，突出可用状态 |
| `reserved` | 已预留 | 仍展示，但说明暂不接受新的购买请求 |
| `sold` | 已售出 | 降低视觉强调并加已售标记；是否保留由后续决定 |

## 图片规范草案

- 使用白色或接近白色的统一背景
- 商品主体尽量居中，并保留相似的四周留白
- 首图建议使用统一的宽高比
- 原图保留归档，网站使用压缩后的 WebP 或 AVIF
- 文件名使用商品 ID 和顺序，例如 `chair-001-01.webp`
- 为每张图片填写简短的替代文字，方便无障碍浏览和图片加载失败时识别
